#### Задание 2
В файле **README.md** написать следующие запросы для **MongoDB**:
const books = db().collection('books');
 - запрос(ы) для *вставки* данных минимум о двух книгах в коллекцию **books**,
 await books.insertMany([
  {
    title: "Разбуди в себе исполина",
    description: "Книга о том, как научиться контролировать себя, здоровье, деньги и окружающих людей. Она научит собрать волю в кулак и управлять своей жизнью.",
    authors: "Энтони Роббинс"
  },
  {
    title: "Самый богатый человек в Вавилоне",
    description: "Здесь вы прочитаете много секретов о зарабатывании денег.",
    authors: "Джордж Самюэль Клейсон"
  },
])
 - запрос для *поиска* полей документов коллекции **books** по полю *title*,
 await.books.find({ title: "Самый богатый человек в Вавилоне" })
 - запрос для *редактирования* полей: *description* и *authors* коллекции **books** по *_id* записи.
 await db.books.updateOne(
  { _id: ObjectId("id конкретной записи") },
  { 
    $set: { 
      description: "Новое описание",
      authors: "Новый автор" 
    } 
  }
)
*Каждый документ коллекции **books** должен содержать следующую структуру данных: 
```javascript
{
  title: "string",
  description: "string",
  authors: "string"
}
```
